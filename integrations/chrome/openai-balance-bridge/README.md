# JARVIS OpenAI Balance Bridge

1. Abra `chrome://extensions` no Chrome normal.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione `D:\python\ServicesBI_Jarvis\integrations\chrome\openai-balance-bridge`.

A extensão tem ID determinístico `aacaopfflcfcocgpnklfggpmkjacbilc`. Ela acessa somente a OpenAI Platform e o backend local do JARVIS. Nenhum cookie, token, HTML ou credencial é transmitido.
